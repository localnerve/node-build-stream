# node-build-stream 1.0.0

node-build-stream is a streaming build runner for Node.js projects that want
Gulp's familiar file-object and plugin workflow without Gulp's runtime
dependency tree. It replaces Gulp's core source, destination, and task-running
layers with Node.js streams and promises, while remaining compatible with the
large ecosystem of Gulp plugins that operate on Vinyl file objects.

The package requires Node.js 24 or newer and has zero runtime dependencies: its
implementation uses `node:` built-ins. If a consuming project already has
`vinyl` installed, node-build-stream can use that package for plugin
compatibility; otherwise it provides its own lightweight `File` class.

Builds are ordinary JavaScript modules. `src()` resolves files into a stream of
File objects, transforms operate on those objects, and `dest()` writes their
contents while preserving paths. `task()`, `series()`, and `parallel()` provide
Promise-based task composition. The CLI runs build files directly, so projects
can keep build logic in JavaScript instead of maintaining a separate task
configuration format.

## What's included

- **Multiple named CLI tasks.** `nbs task-a task-b` runs tasks concurrently by
  default. Add `--series` to run them sequentially in command-line order.
  Concurrent tasks share one process and wait for all started work to settle
  before reporting a failure; serial execution stops at its first failure.
- **Gulp CLI migration aliases.** `--tasks` aliases `--list`, including JSON
  output. The unsupported `--verbose` flag now fails with guidance to remove
  it; build-specific options remain available to the build module.
- **Per-pattern output paths.** Every matched file receives a base derived
  from the concrete positive pattern that matched it. Mixed patterns and brace
  alternatives can therefore preserve their own intended relative paths;
  explicit `base` overrides remain available.
- **Safer destinations.** `dest()` rejects output paths that resolve outside
  its destination directory rather than writing beyond the requested folder.
- **Migration-focused guidance.** The guides explain empty and out-of-working-
  directory glob results, generated `File` output, same-directory read/write
  considerations, task and schedule pitfalls, and checking rewritten bundle
  contents in fingerprinting pipelines.
- **Typed public API and practical examples.** JSDoc-generated TypeScript
  declarations, a basic runnable example, and a multi-stage webapp pipeline
  help teams adopt and verify the API.

## Getting started

Install node-build-stream in a Node.js 24+ project, create a JavaScript build
module, and invoke it with the bundled `nbs` CLI. For a first build and the
complete API reference, see [Getting started](../getting-started.md) and
[the API reference](../api.md). The repository README includes a runnable
example and links to guides for tasks, streams, files, globbing, and Gulp plugin
interop.
